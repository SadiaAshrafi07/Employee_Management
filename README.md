# Employee_Management
# 👨‍💼 Employee Management System – MySQL

A simple **Employee Management Database** built using **MySQL** to demonstrate fundamental SQL concepts such as database and table creation, data insertion, table modification, filtering unique values, column aliases, and retrieving employee records.

---

## 📌 Project Overview

This project demonstrates how to create and manage an employee database using MySQL.

The database stores essential employee information such as:

- Employee ID
- Employee Name
- Department
- Salary
- Joining Date

The project is designed as a beginner-friendly SQL practice project and covers several important **DDL and DML operations**.
